# 视觉模型与训练

更新日期：2026-10-11（Asia/Shanghai）

## 1. 当前定位

DermFM-Zero-Open 是 DermaGuard 的可替换本地视觉 Provider。视觉层只输出候选类别和分数，不直接决定诊断、风险等级、挂号或护理路径。分诊、结构化问诊、RAG 证据和 LLM 归因均位于 Provider 之外。

当前存在两种输出：

1. 六候选类零样本图文匹配分数，用于官方模型冒烟验证。
2. 冻结视觉主干上训练的 HAM7 皮肤镜线性任务头，用于七分类研究原型。

两者均不能称为临床患病概率，不能替代皮肤科医生。

## 5. 数据与疾病覆盖

技术报告说明，发布版从 PanDerm 视觉编码器初始化，再使用 517,455 个公开来源图文对训练，其中临床照片 406,831 张（79%），皮肤镜图像 110,624 张（21%）。

作者用于零样本分类评测的数据集包括 HAM 7 类、PAD 6 类、ISIC2020 2 类、PH2 2 类、SNU 134 类、SD-128 128 类和 Daffodil 5 类。`DERM1M_CLASSNAMES` 含 407 个字符串，但包含同义词、亚型和少量非疾病词，不能解读为“可诊断 407 种病”。

当前应用侧有 60 类中英文零样本候选集，完整机器可读覆盖信息位于 `backend/app/knowledge/dermfm_disease_coverage.json`。词汇或训练数据覆盖不等于已获得该疾病的临床精度。

`data/public_examples/isic/` 保存 5 张 ISIC Archive CC-0 样例，包括黑色素瘤、基底细胞癌、色素痣、脂溢性角化病和皮肤纤维瘤。来源和校验值见同目录 `manifest.json`。

## 6. HAM7 最小任务头

不混合不同成像模态的官方数据集。当前只在 `HAM-official-7-lp` 官方划分上训练一个皮肤镜线性头，DermFM-Zero 主干完全冻结。

| 集合 | 数量 | 用途 |
|---|---:|---|
| 训练集 | 8012 | 训练 `Linear(768, 7)` |
| 验证集 | 500 | 选择权重方案、随机种子和停止轮次，并做温度校准 |
| 测试集 | 1503 | 完成选模后评估一次 |

七类为日光性角化病、基底细胞癌、良性角化病、皮肤纤维瘤、黑色素瘤、色素痣和血管性病变。可训练参数为 5,383。

实际选中随机种子 1000、不使用类别加权、第 124 轮：

| 测试指标 | 结果 |
|---|---:|
| Accuracy | 89.29% |
| Balanced Accuracy | 79.34% |
| Macro-F1 | 80.98% |

公开色素痣样例预测为色素痣 85.30%；但皮肤纤维瘤样例仍误判，基底细胞癌样例虽为 Top-1 但信心度仅 37.04%。因此必须保留低置信度拒判和人工复核。

该任务头现已接入实际 Web/API 推理链：`frozen_dermfm_worker.py` 加载冻结 DermFM 图像编码器后，使用与训练一致的 `Resize(256) → CenterCrop(224) → Normalize(0.5, 0.5)` 预处理，输出归一化的 768 维特征，再加载 `ham7_linear_head.pt` 完成分类、温度缩放与拒识判断。HAM 皮肤镜工作流不再把60类零样本相似度作为网页主结果。

## 7. 训练日志与可视化

训练目录 `artifacts/training/ham7_linear_head/` 保存：

- `ham7_linear_head.pt`：线性头权重与校准信息。
- `training.log`：完整运行日志。
- `run_config.json`：命令、环境、GPU、参数和数据划分。
- `epoch_history.csv`：逐轮训练损失和验证指标。
- `candidate_summary.csv`：九组随机种子与类别权重对比。
- `test_predictions.csv`：1503 张测试图的逐样本概率和预测。
- `per_class_metrics.csv` 和 `confusion_matrix.csv`：分类指标与混淆矩阵。
- `training_evaluation.png`：中文训练曲线、候选对比、分类指标和混淆矩阵。

复现：

```bash
conda run -n dermfm-zero python scripts/train_dermfm_linear_head.py \
  --device cuda --batch-size 16 --workers 4 --refresh-features

MPLBACKEND=Agg conda run -n dermfm-zero \
  python scripts/visualize_training_results.py
```

不加 `--refresh-features` 时重用现有特征缓存，只重新训练线性头。

## 9. 下一阶段原则

PAD 临床照片应使用自己的官方划分单独训练任务头。推理时先区分皮肤镜与临床照片，再路由到对应头。只有建立统一标签映射、患者级去重和外部验证方案后，才考虑联合训练。
